📡 ENDPOINT_LATEST.JSON

GET /api/latest

Returns the latest 10 verified sites for external embeds or community feeds.

Sample Response (200 OK)

{
  "count": 10,
  "sites": [
    {
      "title": "Rohit's Garden",
      "url": "https://rohit.me"
    }
  ]
}

Headers & Caching

  • CORS Header: Access-Control-Allow-Origin: *
  • Cache Control: public, max-age=60, s-maxage=300, stale-while-revalidate=600
  • Returns only verified sites (status='verified').

Example JavaScript Embed

fetch('https://webring.blackpiratex.com/api/latest')
  .then(res => res.json())
  .then(data => {
    data.sites.forEach(site => {
      console.log(site.title, site.url);
    });
  });
