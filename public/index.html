What?

A webring is a list of websites that are linked together. It helps you to find handmade amateur websites. This webring is made specifically for Indian hobbyist and(or) amateur webmasters to showcase their site.

Why?

I have found a lot of cool people from my country (India) who run their own personal site/blog. I want to build a directory for others to find cool personal sites

How to Join?

Enter your details in the form below and it would be automatically saved. Save your token somewhere safe. For verification login to your dashboard and click on verify after adding the webring widget link to your site. It must be anywhere on the homepage, the verification process fetches your domain's root html (for example if your domain is blackpiratex.com it fetches https://blackpiratex.com only and checks if the widget is present) and checks for the widget. If found it automatically verifies it. If you want to add the widget someplace else, please send me an email for manual verification at sudip@blackpiratex.com. All users can add upto two websites, if you want to add more websites, send me an email.

Eligibility

  • Handmade personal sites only, No ads, no commercial sites
  • Must have respectable amount of content. Handmade single page websites are allowed but must have decent amount of texts or images
  • I reserve the right to delete any site at my own discretion

Privacy

Your site name, email, and website url are saved in the db. Your token is saved as a one-way hash, so it cannot be recovered if you lose it. Email is purely optional and for me to contact you, if necessary.

Webring Updates

  • May 9, 2026: Member secret keys are now saved as one-way hashes instead of readable text in the database.
  • May 9, 2026: If you lose your dashboard key, I can now generate a one-time reset link that creates a new secret key for you.
  • May 9, 2026: The database migration now safely moves existing members to hashed keys and removes the old plain token column.
